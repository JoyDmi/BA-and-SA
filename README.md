# BA-and-SA
От Бизнес-требований к Системному проектированию Сквозная инженерия требований: симбиоз Бизнес-аналитика (BA) и Системного аналитика (SA)
Рассматриваемые вопросы в данной презентации:
1. Какой алгоритм действий я должен пройти, чтобы из бизнес требования получить системные требования? 
2. Как понять, где находится граница между бизнес требованием и системным требованием.
3. Что необходимо описывать первым: use case, схема процесса, матрица поведения, модель данных или что-то другое?
4. Как писать формулировки, есть ли требования по описанию?
5. Как понять, что системные требования полностью описаны?
6. Как понять, какая система или модуль должны быть использованы в системном анализе по описанию бизнес процесса?
